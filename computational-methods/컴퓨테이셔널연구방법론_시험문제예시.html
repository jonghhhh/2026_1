문제 A-1 (출력 예측)

아래 코드를 실행했을 때 화면에 출력되는 내용을 모두 순서대로 작성하시오. (별도 설명 불필요)

온도 = 28
습도 = 75
if 온도 >= 30:
    날씨 = "매우 더움"
elif 온도 >= 25 and 습도 >= 70:
    날씨 = "후텁지근함"

문제 A-2 (코드 설명)

아래 코드가 무엇을 실행하는지 설명하시오. (객체, 조건문, 함수 등에 대한 언급 필요)

과목 = \["국어", "영어", "수학", "과학"]
통과 = \[True, False, True, True]
실패\_수 = 0
for i in range(len(과목)):
    if 통과\[i]:
        print(f"{과목\[i]}: 합격")
    else:
        print(f"{과목\[i]}: 불합격")
        실패\_수 += 1
print(f"불합격 과목: {실패\_수}개")
