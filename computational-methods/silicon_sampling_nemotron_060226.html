1. 실리콘 샘플링이란?

AI(LLM)에게 특정 사람인 척 설문에 답하게 한 뒤, 그 답변 분포를 진짜 여론처럼 활용할 수 있는지 검증하는 방법론

쉬운 비유

62세 영남 거주 보수 성향 남성 1,000명에게 설문을 직접 받으려면?

  • 사람 모집: 몇 달
  • 비용: 수백만 원
  • 실제 응답률: 10% 이하

실리콘 샘플링은 이렇게 합니다:

AI에게 알려줍니다 →  "당신은 62세, 경남 창원 거주, 보수 성향 남성입니다." (페르소나 구현)
그리고 물어봅니다 →  "빈부 격차가 얼마나 심각하다고 생각하세요?"
AI가 답합니다   →  "③ 약간 심각하다"

이것을 서로 다른 페르소나 AI에게 1,000번 반복 → 분포 완성!

왜 연구자들이 관심 갖는가

전통 여론조사           실리콘 샘플링
─────────────          ─────────────
비용: 수백만 원    vs   비용: 수천 원
시간: 수주         vs   시간: 수시간
응답률: 5~15%      vs   응답률: 100%
그러나 진짜 사람   vs   AI가 생성 → 정확도 검증 필요!

중요한 전제

실리콘 샘플링은 “대체재”가 아니라 “보조 도구” 입니다.
실제 여론조사와 얼마나 비슷한지 항상 검증해야 합니다.

2. 오늘의 재료

재료 1: Nemotron-Personas-Korea

NVIDIA가 공개한 합성 한국인 페르소나 데이터셋입니다.

(https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea)

합성(synthetic) = 실제 개인 정보 없음, 통계적으로 진짜 같음

실제 한국 인구 통계청 데이터
        ↓
인구 분포 반영해서 가상 한국인 생성
        ↓
약 100만 명의 가상 한국인 프로파일

각 페르소나에는 두 종류 정보가 있습니다:

종류 예시
구조화 정보 성별: 여자 / 나이: 53 / 지역: 경남 창원 / 학력: 고졸
서사 정보 “창원 공단에서 잔뼈가 굵은 꼼꼼한 생산관리자로, 가족을 향한 헌신과 실용적인 삶의 태도를 지닌 50대 여성”

서사 정보 덕분에 AI가 단순한 통계 태그가 아니라 입체적인 인물로 응답하게 됩니다.

Step 0: 필요한 라이브러리 설치

Step 2: Nemotron 데이터셋 로드

처음 실행 시 자동으로 데이터를 다운로드합니다 (약 수백 MB).

첫 번째로 할 일: 컬럼 이름 확인

출력된 컬럼 이름을 보고 아래 코드의 필드명을 맞춰주세요.

Step 3: 1,000명 샘플링

sample_df = df.sample(n=1000, random_state=42)

random_state=42를 쓰면 누가 실행해도 똑같은 1,000명이 뽑힙니다. 이것이 재현 가능성(reproducibility) 의 핵심입니다.

Step 4: 페르소나 → 프롬프트 변환

각 사람의 정보를 AI가 읽을 수 있는 텍스트로 만듭니다.

def build_prompt(persona):
    return f"""당신은 다음과 같은 한국인입니다:
    
성별: {persona['gender']} / 나이: {persona['age']}세
거주지: {persona['region']} / 직업: {persona['occupation']}

{persona['bio']}  ← 여기가 서사(이야기) 정보

위 인물의 입장에서 솔직하게 답하세요.
"""

구조화 정보 + 서사 정보가 합쳐져야 AI가 더 사실적으로 답합니다.

비교해 보세요:

서사 없이:  "53세 여성, 고졸, 생산직"
서사 포함:  "53세 여성, 고졸, 생산직. 창원 공단에서 잔뼈가 굵은 
              꼼꼼한 관리자로, 가족을 향한 헌신과 실용적인 삶의 태도를..."

서사가 있으면 AI가 훨씬 구체적이고 일관된 캐릭터로 응답합니다.

Step 6: 응답 파싱 (텍스트에서 보기 추출)

AI는 자유 문장으로 답하므로, 선택지를 뽑아내야 합니다.

AI 응답: "③ 약간 심각하다고 생각합니다. 주변에서도..."
         ↓
파싱 →  "약간 심각하다"

3단계 안전망:

  1. 텍스트 직접 매칭: “약간 심각하다”가 응답에 있나?
  2. 번호 기호 매칭: ①②③④ 있나?
  3. 숫자 매칭: 1,2,3,4 있나?
  4. 모두 실패 → “모름/무응답”

Step 7: 결과 저장

5. 결과 해석 방법

분포 읽기

빈부 격차 심각성 인식 분포 (예시)

전혀 심각하지 않다  ██              3%
별로 심각하지 않다  ████████       10%
약간 심각하다       ████████████████████  47%
매우 심각하다       ████████████████    40%

주의할 점 3가지

  1. 균질화(homogenization)
    AI는 실제보다 분포를 더 좁게(한쪽으로 치우치게) 만드는 경향이 있습니다.
    → 다양성이 실제보다 낮을 수 있음
  2. 사회적 바람직성 편향
    AI는 “사회적으로 좋아보이는 답”을 선호합니다.
    → 민감한 질문(이민, 성소수자 등)에서 특히 주의
  3. 진짜 여론조사와 비교 필수
    실리콘 샘플링 결과만 보지 말고, 실제 여론조사 결과와 함께 놓고 비교해야 의미가 있습니다.
