프롬프트로 JS 시각화 가이드: 교통사고 데이터 활용

이 가이드는 도로교통공단(TAAS) 표준데이터(전국교통사고다발지역표준데이터-20260301.xls, 12,780행)를 가지고 5개 학습 가이드 HTML(js_charts.html, js_more_charts.html, js_network.html, js_map.html, js_scrollytelling.html)에 나오는 모든 시각화를 그대로 만들어 본다.

가이드의 사용법 — 자연어 프롬프트 원칙

초보자를 위해 모든 프롬프트는 짧은 자연어 한두 문장으로 작성했다. 색상·크기·세부 옵션을 처음부터 다 적지 않는다. 첫 결과를 받은 뒤 마음에 안 드는 부분이 있으면 다음과 같이 자연어로 수정 요청하면 된다.

  • "막대 더 두껍게"
  • "색 빨간색으로"
  • "y축 숫자에 천 단위 콤마"
  • "2020년만 다른 색으로 강조"
  • "글자 크게"
  • "두 개 차트 나란히"

좋은 시각화는 첫 프롬프트로 끝나지 않는다. Gemini와 4~5번 주고받으며 다듬는 게 정상이다. 이 과정 자체가 데이터저널리즘 실습의 핵심이다.

Part 0. 데이터 변환 — Excel → 단일 JSON

0.1 왜 JSON으로 바꾸는가

.xls는 JS에서 직접 못 읽고, CSV는 한글 인코딩과 따옴표 문제가 있다. JSON은 fetch().then(r => r.json()) 한 줄로 객체 배열이 된다. 그리고 Chart.js·Leaflet·D3·vis-network 등 본 강의에서 쓰는 모든 라이브러리가 객체 배열을 그대로 받아들인다.

초보자가 헷갈리지 않도록 모든 시각화가 단 하나의 data.json 파일을 참조한다. 12,780행이 그대로 들어가지만 1~2MB 수준이라 충분히 가볍다. 시각화별로 필요한 부분(연도별 합계, 시도별 합계, 위경도 점 등)은 JS 안에서 그때그때 집계하면 된다. 학생이 차트 만들면서 "이번엔 시도별로 묶어서 사고건수 합계만 필요하다"는 걸 자연스럽게 익히게 된다.

0.2 변환 스크립트 (Python)

convert_to_json.py로 저장 후 한 번만 실행한다. 결과로 data.json 하나가 생긴다.

import pandas as pd

# 원본 로드 (xls는 xlrd 엔진 필요: pip install xlrd)
df = pd.read_excel(
    "전국교통사고다발지역표준데이터-20260301.xls",
    engine="xlrd"
)

# 시도 컬럼 파생: "서울특별시 강남구1" → "서울특별시"
df['시도'] = df['사고다발지역시도시군구'].str.split().str[0]

# 끝에 붙은 숫자 제거 (예: "세종특별자치시1" → "세종특별자치시")
df['시도'] = df['시도'].str.replace(r'\\d+$', '', regex=True)

# 한 줄짜리 폴리곤 컬럼은 너무 무거우니 제거 (시각화에 안 씀)
df = df.drop(columns=['사고다발지역폴리곤정보'])

# JSON으로 저장 (한글 그대로 유지)
df.to_json("data.json", orient="records", force_ascii=False, indent=2)

print(f"data.json 생성 완료: {len(df):,}행")

0.3 Gemini용 변환 프롬프트

위 스크립트를 직접 짜지 않고 Gemini에게 맡길 때:

첨부한 교통사고 다발지역 xls 파일을 data.json 하나로 변환하는 Python 스크립트 만들어줘. 사고다발지역시도시군구 컬럼에서 시도(서울특별시, 경기도 등)를 따로 뽑아서 시도 컬럼을 추가해줘. 폴리곤 컬럼은 빼고. 한글 그대로 유지되게.

0.4 data.json 구조 미리보기

생성된 파일은 객체 배열이고 한 행은 다음과 같다.

{
  "사고지역관리번호": 2025108,
  "사고연도": 2024,
  "사고유형구분": "보행어린이",
  "사고다발지역시도시군구": "전북특별자치도 정읍시1",
  "사고지역위치명": "전북특별자치도 정읍시 상동(한솔초등학교 부근)",
  "사고건수": 3,
  "사상자수": 3,
  "사망자수": 0,
  "중상자수": 0,
  "경상자수": 3,
  "부상신고자수": 0,
  "위도": 35.560543,
  "경도": 126.873488,
  "데이터기준일자": "2025-09-24",
  "시도": "전북특별자치도"
}

JS에서는 이렇게 쓴다.

fetch('./data.json')
  .then(r => r.json())
  .then(data => {
    // data는 12,780개 객체의 배열
    // 예: 연도별 사고건수 합계 만들기
    const byYear = {};
    data.forEach(d => {
      byYear[d.사고연도] = (byYear[d.사고연도] || 0) + d.사고건수;
    });
    console.log(byYear);
  });

위 패턴(fetch → forEach → 누적)만 익히면 어떤 시각화든 만들 수 있다.

Part 1. 기본 차트 10종 (js_charts.html)

A1. Bar — 연도별 사고건수

  • 보여주는 것: 13년치 사고건수 흐름
  • 사례 포인트: 2020년 코로나로 줄어든 변곡점

data.json에서 연도별 사고건수 합계를 막대 그래프로 그려줘. Chart.js로. 파란색 계열. 2020년 떨어진 게 잘 보이게.

다듬을 때: "2020년만 빨간색으로 강조" / "y축 숫자에 천 단위 콤마" / "막대 좀 더 두껍게"

A2. Line 이중축 — 사고건수 vs 사망자

  • 보여주는 것: 두 지표가 같이 움직이는지 / 따로 움직이는지
  • 사례 포인트: 단위가 다른 두 지표(만 단위 vs 명 단위)를 한 화면에 비교

data.json에서 연도별 사고건수와 사망자수를 두 줄로 그려줘. Chart.js 라인차트. 단위가 다르니까 왼쪽 오른쪽 축 따로 써줘. 사고건수는 파란색, 사망자는 빨간색.

다듬을 때: "마우스 올리면 두 값 동시에 보이게" / "선 아래 영역도 색칠해줘"

A3. Pie와 Doughnut — 사고유형 비율

  • 보여주는 것: 4가지 사고유형 중 어느 것이 가장 많은가
  • 사례 포인트: 보행노인이 절반 이상 — 한눈에

data.json의 사고유형구분 4가지(보행노인, 자전거, 보행어린이, 스쿨존어린이) 비율을 파이차트와 도넛차트 두 개로 나란히 그려줘. Chart.js. 마우스 올리면 % 같이 보이게.

다듬을 때: "범례 위치를 오른쪽으로" / "도넛 가운데에 합계 숫자 넣어줘"

A4. Radar — 시도별 다차원 비교

  • 보여주는 것: 여러 시도의 사고건수·사망자 패턴 비교
  • 사례 포인트: 단위 다른 두 지표를 함께 그릴 때는 0~100 정규화 필수

data.json에서 사고건수 상위 7개 시도를 골라서 사고건수와 사망자수를 레이더차트로 그려줘. Chart.js. 두 지표 단위가 너무 다르니까 둘 다 0~100 사이로 정규화해서. 사고건수는 파란색, 사망자는 빨간색 면.

다듬을 때: "도형 더 진하게" / "꼭짓점에 점 표시"

A5. Bubble — 시도별 3변수

  • 보여주는 것: 한 차트에 세 변수 동시 (x, y, 원 크기)
  • 사례 포인트: 원 크기는 √변환해야 면적이 값에 비례

data.json으로 17개 시도를 버블차트로 그려줘. Chart.js. x는 사고건수, y는 사망자수, 원 크기는 사상자수에 비례. 시도마다 다른 색. 큰 값이 너무 부풀려지지 않게 원 크기는 제곱근으로.

다듬을 때: "버블 크기 차별화 잘 안 되니 더 크게 차이내" / "각 점에 시도명 라벨 붙여"

A6. Scatter — 사고건수 vs 사망률

  • 보여주는 것: 사고가 많은 곳이 더 위험한가? (양의 상관 / 음의 상관 / 무관)
  • 사례 포인트: 산점도는 상관일 뿐 인과 아님

data.json에서 시도별로 사고건수(x축)와 사망률(y축, 사망자÷사상자×100) 산점도를 그려줘. Chart.js. 점에 시도 이름 붙여서 마우스 올리면 보이게. 보라색 점.

다듬을 때: "추세선 그어줘" / "점 더 크게"

A7. Polar Area — 사고유형 분포 [변형]

  • 보여주는 것: 4가지 사고유형의 상대 크기를 부채꼴로
  • 변형 사실: 원전 사례는 시간대별이지만 본 데이터에 시간 정보가 없어 사고유형으로 대체

data.json의 사고유형 4가지를 Chart.js polarArea로 그려줘. 색은 4가지 다른 색. 차트 아래에 작게 "원래는 시간대 분포가 표준이지만, 이 데이터에 시간 정보가 없어 사고유형으로 대체"라고 적어줘.

A8. Mixed — 막대(사고건수) + 선(사망률)

  • 보여주는 것: 양과 비율을 한 차트에서
  • 사례 포인트: "건수는 줄어도 사망률은 그대로"라는 메시지가 잡힘

data.json으로 연도별 사고건수는 막대(파란색), 사망률(사망자÷사상자×100)은 빨간 선으로 그려줘. Chart.js mixed 차트. 두 지표 단위가 달라서 좌우 축 따로.

다듬을 때: "막대 좀 투명하게" / "선 끝에 점 표시"

A9. Treemap — 시도×사고유형

  • 보여주는 것: 시도 안에 사고유형이 어떻게 분포하는지
  • 사례 포인트: 면적이 곧 양 — 항목 많아도 일관된 표현

data.json으로 시도×사고유형 트리맵 만들어줘. Chart.js 트리맵 플러그인 써서. 시도가 큰 박스, 그 안에 사고유형이 작은 박스. 시도마다 다른 색.

다듬을 때: "박스 안에 숫자 보이게" / "테두리 흰색으로 명확히"

A10. 인터랙티브 필터 — 드롭다운

  • 보여주는 것: 학생/독자가 직접 지표·차트 종류·기간을 바꿔가며 탐색
  • 사례 포인트: 인터랙티브 차트의 핵심 패턴

data.json으로 인터랙티브 차트 만들어줘. Chart.js. 위에 드롭다운 세 개: 지표(사고건수/사망자/사상자/중상/경상), 차트 종류(막대/선/레이더/폴라), 표시 기간(2~13년). 드롭다운 바꿀 때마다 차트 다시 그려지게.

다듬을 때: "차트 바뀔 때 부드럽게 애니메이션" / "드롭다운 라벨 한국어로 명확히"

Part 2. 특수 시각화 9종 (js_more_charts.html)

B1. 워드클라우드 — 위치명 키워드

  • 보여주는 것: 다발지역 이름에 자주 등장하는 단어
  • 사례 포인트: "사거리, 교차로, 부근, 초등학교" 같은 공간 키워드 발견

data.json의 사고지역위치명 12,780개를 합쳐서 워드클라우드 만들어줘. D3 + d3-cloud 라이브러리. 한국어 불용어(은/는/이/가 등) 제외하고 빈도 상위 80개. 색은 알록달록하게.

다듬을 때: "'부근' 단어가 너무 커서 빼줘" / "회전 0도만"

B2. Sankey — 사고유형 → 시도 → 상해등급

  • 보여주는 것: 단계별 흐름의 양 (어느 유형이 어느 시도에 몰리고 어떤 결과로 이어지는지)
  • 사례 포인트: 합계 보존 — 들어온 만큼 나간다

data.json으로 Sankey 다이어그램 만들어줘. 1단계는 사고유형 4가지, 2단계는 사고건수 상위 5개 시도, 3단계는 상해등급(경상·중상·사망). Chart.js sankey 플러그인. 흐름 두께가 건수.

다듬을 때: "사망 흐름만 빨간색으로" / "라벨 글자 크기 키워"

B3. Calendar Heatmap — 시도×연도 [변형]

  • 보여주는 것: 시도와 연도 교차로 사고가 어떻게 분포했는지
  • 변형 사실: 원전 사례는 일자별이지만 본 데이터에 일자가 없어 연도로 대체

data.json으로 시도(세로) × 연도(가로) 히트맵 그려줘. ApexCharts. 칸 색은 사고건수에 따라 분홍 그라디언트. 진할수록 사고 많은 칸. 차트 아래에 "원래 캘린더 히트맵은 일자별이지만 이 데이터에 일자가 없어 연도로 변형"이라고 적어줘.

B4. Sunburst — 권역→시도→사고유형

  • 보여주는 것: 3단계 계층 비율을 방사형으로
  • 사례 포인트: 클릭하면 그 영역만 줌인 가능

data.json으로 3단계 sunburst 만들어줘. 시도를 5개 권역(수도권: 서울·경기·인천 / 영남: 부산·대구·울산·경남·경북 / 호남: 광주·전남·전북 / 충청: 대전·세종·충남·충북 / 강원·제주)으로 묶고, 권역→시도→사고유형 3계층. Plotly로. 핑크 계열 색.

다듬을 때: "각 조각에 % 같이 표시" / "가운데 색 더 진하게"

B5. Parallel Coordinates — 17시도 다변수

  • 보여주는 것: 17개 시도의 4개 지표(사고건수·사망자·사망률·사상자)를 한 화면에서
  • 사례 포인트: 축을 드래그하면 그 범위만 필터됨

data.json으로 17개 시도를 평행좌표로 그려줘. Plotly parcoords. 4개 축: 사고건수, 사망자, 사망률(%), 사상자. 선 색은 사망률에 따라 그라디언트.

다듬을 때: "축 라벨 잘려서 안 보이니 위쪽 여백 늘려" / "특정 시도 강조해줘"

B6. Matrix Heatmap — 사고유형×시도 [변형]

  • 보여주는 것: 두 분류의 교차를 색 농도로
  • 변형 사실: 원전 사례는 시간×요일이지만 본 데이터에 시간/요일 없어 유형×시도로 대체

data.json으로 사고유형(세로 4개) × 시도(가로 17개) 매트릭스 히트맵을 그려줘. Chart.js matrix 플러그인. 사고건수가 많을수록 진한 분홍. 마우스 올리면 칸 정보 보이게.

B7. Box Plot — 시도별 다발지역 분포

  • 보여주는 것: 평균뿐 아니라 분산·이상치까지
  • 사례 포인트: "경기도는 평균도 높고 변동도 큼" 같은 패턴

data.json에서 다발지역이 많은 상위 7개 시도를 골라, 각 시도의 다발지역별 사고건수 분포를 박스플롯으로 그려줘. Plotly. 이상치는 점으로 표시.

다듬을 때: "박스 너비 더 넓게" / "각 박스 아래에 시도 이름과 평균값 표시"

B8. Gauge / KPI — 4개 핵심지표 카드

  • 보여주는 것: 단일 핵심 수치를 부각 (전년 대비 변화 포함)
  • 사례 포인트: 대시보드 상단에 자주 쓰는 형태

data.json에서 2024년과 2023년 비교해서 4개 KPI 카드(사고건수, 사망자, 사상자, 사망률) 만들어줘. Plotly indicator. 게이지 + 숫자 + 전년 대비 화살표. 2x2 격자로.

다듬을 때: "악화한 건 빨간 화살표 개선한 건 초록 화살표" / "카드 제목 더 크게"

B9. Funnel — 사고에서 사망까지 단계별 감소

  • 보여주는 것: 단계가 진행될수록 줄어드는 양
  • 사례 포인트: 절대값 + 첫 단계 대비 비율 동시 표시

data.json의 2024년 합계로 깔때기 차트 그려줘. 단계: 사고 → 사상자 → 경상 → 중상 → 사망. Plotly funnel. 단계마다 절대값과 첫 단계 대비 비율도 표시.

Part 3. 네트워크 시각화 7종 (js_network.html)

N3. 계층 Tree — 전국→권역→시도→유형

  • 보여주는 것: 4계층 위계 구조
  • 사례 포인트: 위→아래로 정렬된 깔끔한 트리

data.json으로 4계층 트리 그려줘. vis-network 계층 레이아웃. 전국 → 5권역 (수도권/영남/호남/충청/강원·제주) → 시도 → 사고유형. 위에서 아래로. 권역은 진한 파란색.

다듬을 때: "방향 좌→우로" / "각 노드에 합계 숫자 같이"

N4. D3 Force-Directed — 3그룹 다중 카테고리

  • 보여주는 것: 시도·유형·연도구간 세 그룹의 관계망
  • 사례 포인트: 학술 논문급 시각화 가능, 자유도 높음

data.json으로 3그룹 force-directed 네트워크 만들어줘. D3 v7. 그룹은 ① 시도 상위 7개 ② 사고유형 4개 ③ 연도구간 3개(2012-2015, 2016-2019, 2020-2024). 그룹마다 다른 색. 자기들끼리 자동 배치.

N5. Cytoscape Dagre — 권역 계층 + 레이아웃 전환

  • 보여주는 것: 같은 데이터를 여러 레이아웃으로 즉시 전환
  • 사례 포인트: 그래프 분석 라이브러리의 강점

data.json으로 23개 노드 트리(전국 + 5권역 + 17시도)를 Cytoscape + dagre로 그려줘. 위에 드롭다운 두고 dagre / cose / circle / grid / concentric 레이아웃 즉시 전환되게.

N6. 인터랙티브 조작 ⭐ — 노드 추가·삭제·이웃 강조

  • 보여주는 것: 학생이 직접 그래프를 편집하며 가설 구성
  • 사례 포인트: 학생 미션용

data.json의 시도 5개 + 사고유형 4개를 베이스로, vis-network 인터랙티브 편집기 만들어줘. 버튼으로 노드 추가, 엣지 추가, 선택 삭제, 화면 맞춤, 초기화 가능하게. 노드 클릭하면 그 노드와 직접 연결된 이웃만 진하고 나머지는 흐리게.

N7. 의미연결망 ⭐ — 위치명 단어 동시출현

  • 보여주는 것: 사고지역위치명에서 어떤 단어들이 함께 나타나는가
  • 사례 포인트: 본 데이터의 강점이 가장 잘 살아나는 시각화

data.json의 사고지역위치명을 모두 합쳐서 의미연결망 만들어줘. vis-network. 한 위치명 안에 두 단어가 같이 나오면 선 연결. 상위 25개 단어가 노드, 동시출현 2회 이상이 엣지. 한국어 불용어 제거. 위에 단어 수랑 최소 동시출현 횟수 조절하는 컨트롤도.

다듬을 때: "'부근' 단어가 거의 모든 단어와 연결돼서 의미 흐려져 — 빼줘" / "노드 크기 차이 더 크게"

M4. 히트맵 — 전국 사고 밀집도

M6. 폴리라인/폴리곤/원 — 경로·영역·반경

  • 사례 포인트: GPS 트랙·관심영역·반경원 표현 도구
